
# Plant Nursery Management and Online Ordering System

## Project Overview
The Plant Nursery Management System is a web-based application developed using ASP.NET Core MVC. It helps customers browse plants and place orders online. Admins can manage plants, categories, customers, and orders.

## Technologies Used
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML, CSS, Bootstrap
- JavaScript

## Main Features
- Customer registration and login
- Browse and view available plants
- Online plant ordering
- Shopping cart and order management
- Admin dashboard
- Manage plants and categories
- Customer and order management

## Database
SQL Server is used to store customer, plant, category, and order information. Entity Framework Core is used for database operations.

## How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio.
3. Update the SQL Server connection string in `appsettings.json`.
4. Apply Entity Framework Core migrations if required.
5. Run the application.
